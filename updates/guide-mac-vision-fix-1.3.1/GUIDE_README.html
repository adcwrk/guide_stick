GUIDE

Grounded Unified Intelligence for Disaster & Emergency Response

An offline-first emergency decision support platform for disasters, medical emergencies, infrastructure failures, survival scenarios, and household preparedness.

“It’s not about the gear you have, it’s the decisions you make.”

1. What GUIDE Is

GUIDE helps you make safer, clearer decisions when normal systems are degraded or unavailable. It combines local AI, emergency-focused retrieval, structured response logic, and safety validation so it can keep working even when internet access is limited or unavailable.

Best use: Ask GUIDE practical questions about emergency response, first aid, power, water, communications, supplies, evacuation planning, and household readiness.

2. First Launch

1
Start GUIDE.
Open the GUIDE launcher, dashboard, or local web address provided with your system.
2
Wait for the local AI engine.
The first launch may take longer while the local model loads into memory. This is normal.
3
Check system status.
Confirm that the dashboard shows the local model, retrieval system, document index, and storage path as available.
4
Open chat.
Use the chat page to ask questions, describe incidents, or request checklists.

Fast Start Prompt

We have a power outage.
Household: 4 people.
One person uses refrigerated medication.
Available gear: battery bank, solar panel, propane stove.
Help me prioritize the next 6 hours.

3. How to Ask GUIDE Better Questions

GUIDE performs best when you provide the situation, people involved, constraints, available supplies, and what decision you need to make.

Include

  • What happened
  • Where you are
  • How many people are affected
  • Known injuries, illnesses, medications, or disabilities
  • Available supplies, tools, power, water, and communications
  • Immediate risks such as fire, flooding, violence, cold, heat, or contamination

Ask For

  • A step-by-step response plan
  • A triage checklist
  • A supply calculation
  • A communications message
  • A risk assessment
  • A decision tree for stay/go, treat/evacuate, conserve/use, or call/wait

4. Example Emergency Prompts

  • “Someone has heavy bleeding from their leg. We have gauze, a tourniquet, and gloves. What should we do first?”
  • “Our water is shut off. We have 12 gallons stored for 3 people. Build a 72-hour ration plan.”
  • “Cell service is down. Draft a short Meshtastic message asking neighbors for medical supplies.”
  • “Wildfire smoke is heavy outside. We have one room, towels, tape, and a box fan. How do we reduce exposure?”
  • “Create a checklist for evacuating with two adults, one child, one dog, and refrigerated medication.”

6. Choosing a Local AI Model

GUIDE includes multiple local models. Use smaller models for speed, larger models for more detailed planning, vision models for picture review, and the embedding model for library search support.

Fast Text Models

  • qwen2.5:0.5b: Fastest basic assistant for short answers, quick checklists, and low-power computers.
  • llama3.2:1b: Lightweight general assistant for simple emergency questions and fast follow-ups.
  • qwen2.5:3b: Balanced daily model for practical planning, household readiness, and concise explanations.

Stronger Planning Models

  • llama3.1:8b: General-purpose model for more complete emergency plans, prioritization, and communications.
  • qwen2.5:14b: Larger planning model for detailed analysis, longer checklists, and more nuanced tradeoffs.
  • deepseek-r1:7b: Reasoning model for step-by-step decisions, triage logic, and comparing options.
  • deepseek-r1:14b: Larger reasoning model for complex decisions when response speed is less important.

Specialized Models

  • qwen2.5-coder:7b: Coding and technical help, scripts, calculations, data formatting, and troubleshooting logic.
  • fluffy/l3-8b-stheno-v3.2:q4_K_M: Creative writing, scenario rehearsal, plain-language announcements, and roleplay drills.
  • AliBilge/Huihui-GLM-4.6V-Flash-abliterated:q4_K_M: General open-ended assistant with moderate size and speed.
  • AliBilge/Huihui-GLM-4.6V-Flash-abliterated:q5_k_m: Higher-quality version of the same general assistant, with slower responses on some computers.

Vision and Retrieval Models

  • moondream:latest: Lightweight picture review for identifying visible objects, labels, supplies, damage, and obvious risks.
  • huihui_ai/qwen2.5-vl-abliterated:7b-instruct: Stronger picture review model for more detailed visual analysis when available.
  • nomic-embed-text:latest: Library search and retrieval support model. It helps GUIDE find relevant local documents and is not intended for normal chat.
Model selection tip: If a model is slow, switch to a smaller model. If an answer is too shallow, switch to a larger or reasoning model. For pictures, use Review Picture with a vision model.

7. Quick Model Picker

Need the fastest answer?

Use qwen2.5:0.5b, llama3.2:1b, or qwen2.5:3b for short checklists and quick follow-ups.

Need the best planning?

Use qwen2.5:14b, llama3.1:8b, or deepseek-r1:14b for tradeoffs, prioritization, and detailed plans.

Need picture review?

Use moondream:latest for fast image checks or qwen2.5-vl for more detailed visual analysis.

Need code or calculations?

Use qwen2.5-coder:7b for scripts, formulas, structured data, and troubleshooting logic.

Need announcements?

Use fluffy/l3-8b-stheno-v3.2 for plain-language scripts, scenario drills, and calm message drafting.

Need local documents?

Turn on library retrieval. nomic-embed-text supports search behind the scenes and should not be used as a chat model.

8. First 10 Minutes Workflow

  1. Assess danger. Move away from fire, floodwater, gas smell, electrical hazards, violence, smoke, or collapse risk if you can do so safely.
  2. Call for help. Contact emergency services, utility providers, medical help, or local authorities when available.
  3. Stabilize people first. Address bleeding, airway, breathing, shock, temperature exposure, and immediate shelter needs.
  4. Ask GUIDE for structure. Describe what happened, who is affected, where you are, and what supplies are available.
  5. Create a checklist. Ask GUIDE to turn the answer into steps you can assign or read aloud.
  6. Log decisions. Record time, action taken, who did it, and what changed.

10. Picture Review

Review Picture lets GUIDE inspect an image such as a supply shelf, first-aid kit, map, equipment, visible damage, label, or checklist.

  • Attach or select a picture in Review Picture.
  • Ask what is visible, what risks stand out, and what to check next.
  • Use moondream:latest for faster image review.
  • Use huihui_ai/qwen2.5-vl-abliterated:7b-instruct for more detailed image review.
  • Do not rely on picture review for hidden damage, unseen hazards, medical diagnosis, or identification that requires professional confirmation.
If you see “No vision model available”: quit GUIDE, quit any separately installed Ollama app, then relaunch GUIDE from the USB launcher.

11. Journal

Use the Journal to keep an incident log, practice notes, and continuity records.

  • Record what happened, when it happened, who was involved, and what action was taken.
  • Track supplies used, symptoms observed, medication temperature checks, radio messages, and follow-up tasks.
  • Keep entries short enough to scan during stress.
  • Review the Journal after a drill to improve household plans and inventory.

12. Offline Verification

  1. Turn off Wi-Fi and disconnect Ethernet.
  2. Launch GUIDE from the USB launcher.
  3. Ask one known good test prompt.
  4. Open the local library or a saved guide.
  5. Run Review Picture with a local image if vision models are included.
  6. Confirm GUIDE does not claim to check live weather, maps, alerts, or internet sources while offline.

13. Privacy and Data Location

GUIDE is designed for local use, but you should still treat the USB drive as sensitive because it may contain household details, journal entries, chat history, uploaded documents, logs, and inventory information.

  • Do not share a GUIDE USB that contains private household, medical, location, or contact details unless you intend to share that information.
  • Keep the USB physically secure.
  • Before lending a USB, remove personal journal entries, chats, uploaded documents, and inventory details if the app provides those controls.
  • When reporting a bug, avoid sending private screenshots unless needed and approved.

14. Emergency Safety Boundaries

  • Medical emergencies: Use emergency services, poison control, urgent care, or licensed clinicians whenever available. GUIDE can help organize immediate first-aid steps but does not replace medical care.
  • Fire, gas, and electrical hazards: Leave the hazard area when safe, avoid ignition sources, stay away from downed lines, and contact emergency services or utilities.
  • Evacuation orders: Follow official public safety instructions over GUIDE.
  • Structural, chemical, rescue, or weapon hazards: Do not attempt dangerous operations without proper training, equipment, and authority.

15. Using GUIDE During an Incident

  1. Stabilize immediate danger. Move away from fire, floodwater, electrical hazards, violence, smoke, or collapse risk if you can do so safely.
  2. Describe the situation clearly. Tell GUIDE what happened, who is affected, and what resources you have.
  3. Follow the highest-priority actions first. GUIDE should prioritize life safety, bleeding control, airway/breathing, shelter, water, communications, and evacuation decisions.
  4. Use checklists. Ask GUIDE to turn guidance into a checklist you can read aloud or assign to others.
  5. Log major decisions. Record time, action taken, people involved, and outcome. This helps with continuity and later handoff.
  6. Escalate when needed. Contact emergency services, medical professionals, utility providers, or local authorities whenever available and appropriate.
Safety note: GUIDE is decision support, not a replacement for emergency services, licensed medical care, or official public safety instructions. When professional help is available, use it.

16. Offline Knowledge Base

GUIDE can use locally stored emergency documents, manuals, maps, checklists, and preparedness references. When retrieval is enabled, GUIDE can ground answers in indexed local material instead of relying only on general model knowledge.

Typical knowledge-base material includes:

  • Preparedness guides
  • First-aid and medical references
  • Power, water, sanitation, and shelter documents
  • Local maps and evacuation information
  • Radio, communications, and message templates
  • Household inventory and emergency plans

17. Inventory and Household Intake

For better recommendations, enter household details and supply information before an emergency.

  • Number of adults, children, elderly people, and pets
  • Medical conditions, medications, allergies, mobility limits, or special circumstances
  • Food, water, fuel, batteries, radios, lighting, sanitation, and first-aid supplies
  • Power sources such as solar panels, batteries, generators, and vehicle chargers
  • Communication tools such as radios, Meshtastic devices, satellite messengers, and local contact plans

18. Emergency Communications

GUIDE can help draft short, clear messages for radio, Meshtastic, SMS, satellite messenger, or printed handoff notes.

Message format:
WHO: Adam, household of 4
WHERE: 123 Main St / north side of town
STATUS: Safe, no injuries
NEED: Drinking water and medication refrigeration
ACTION: Staying in place for now
TIME: 1430 local

Ask GUIDE to compress messages when bandwidth is limited.

19. Common Troubleshooting

  • AI unavailable: Confirm the local model service is running.
  • Retrieval unavailable: Confirm the document index exists and the vector database is available.
  • No documents found: Re-index the knowledge base or check the document storage path.
  • Slow first response: The model may still be loading into memory.
  • Only one model appears: Relaunch GUIDE from the USB launcher so it uses the USB model folder.
  • Picture review fails on Mac: Quit GUIDE, quit any separately installed Ollama app, and launch GUIDE from Guide (Mac).app.
  • Model is too slow: Switch to qwen2.5:3b, llama3.2:1b, or qwen2.5:0.5b.
  • Bad or vague answers: Provide more context and ask for a checklist, decision tree, or source-grounded response.

20. Recommended Daily-Use Practice

  • Run one emergency scenario each week.
  • Update household intake when people, pets, medications, or supplies change.
  • Review inventory monthly.
  • Test offline mode before you need it.
  • Keep a printed copy of critical contacts, medication needs, evacuation routes, and radio channels.

21. Support and Defect Reporting

When reporting an issue, include enough detail for someone else to reproduce it.

  • Computer model and macOS, Windows, or Linux version
  • Which launcher was used
  • Exact error text and screenshot if available
  • Selected model and prompt used
  • Whether the computer was online or offline
  • What happened after restarting GUIDE
  • Mac vision issues: include .internal/diag/ollama-usb.log if present and safe to share

22. What GUIDE Should Not Be Used For

  • Replacing emergency medical services or professional medical evaluation
  • Ignoring evacuation orders or official public safety alerts
  • Performing dangerous electrical, structural, chemical, or rescue operations without proper training
  • Making legal, financial, or medical decisions without qualified professional support when available

GUIDE is built for calm, structured decision-making when conditions are stressful, degraded, or disconnected.
